# Детектор дубликатов файлов

Минимальный стартовый каркас проекта на Python.

Сейчас проект умеет:
- принимать путь к папке;
- проверять, что папка существует;
- рекурсивно обходить файлы;
- собирать базовую информацию о каждом файле;
- выводить найденные файлы в консоль.

Пока это только этап **взаимодействия с файлами**. Поиск дубликатов по хешу можно будет добавить следующим шагом.

## Структура проекта

```text
duplicate_detector/
├── app/
│   ├── main.py                # Точка входа
│   ├── config.py              # Настройки проекта
│   ├── models/
│   │   └── file_info.py       # Модель данных о файле
│   ├── services/
│   │   └── file_scanner.py    # Логика обхода папок и чтения файлов
│   └── utils/
│       └── path_utils.py      # Проверка пути и вспомогательные функции
├── tests/
│   └── test_file_scanner.py   # Простой тест сканера
├── .gitignore
└── README.md
```

## Запуск

Из корня проекта:

```bash
python -m app.main
```

Или сразу с аргументом:

```bash
python -m app.main "C:/Users/Username/Documents"
```

## Что происходит при запуске

1. Программа получает путь к папке.
2. Проверяет, существует ли папка.
3. Обходит все вложенные директории.
4. Для каждого файла сохраняет:
   - полный путь;
   - имя;
   - размер;
   - расширение.
5. Печатает список файлов и общее количество.

## Что можно добавить дальше
